# Docs Update Rule

After every new feature or meaningful code change, update these files (as applicable):

- `README.md` — update if setup steps, stack, or structure changed
- `CHANGELOG.md` — add entry under `[Unreleased]`
- `.claude/context/project_dispatch.md` — update if component tree, models, or patterns changed
- `.claude/context/MEMORY.md` — update if project state changes
- `.claude/context/todo.md` — mark completed items, add new backlog items

This is part of "done" for every task — not optional cleanup.
